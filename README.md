# Learn from Pallavi Gupta

English Grammar for **Class 1–5**, explained in **Hindi and English**, with an admin portal for student logins.

## Features
- 49 grammar topics (Class 1–5) with Hindi + English explanations, rules, examples and memory tricks
- 🔊 Listen to examples and explanations (text-to-speech)
- Practice quiz on every topic, 10-question class tests, stars and progress
- Certificate when a class is completed (printable)
- Public home page with a free demo lesson
- **Admin portal**: add students, auto-generated passwords that work on any device, validity periods, renew, block, WhatsApp sharing, fee/renewal reminders, backup
- Installable on phones (PWA) and works offline

## Setup
1. Edit `config.js` — add WhatsApp number, phone, email and city.
2. Deploy as a static site (GitHub Pages: **Settings → Pages → Branch `main`, folder `/ (root)`**).
3. Admin login link is in the page footer. See `README.txt` for the admin credentials and how to change them.

Built with plain HTML, CSS and JavaScript — no build step.
